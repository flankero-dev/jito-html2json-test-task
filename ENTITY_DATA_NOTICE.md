# HTML named character reference data

`NAMED_ENTITIES` in `html2json.js` is the complete static mapping (2,231 spellings, including legacy spellings without semicolons) from the WHATWG HTML Living Standard:

https://html.spec.whatwg.org/entities.json

Retrieved 2026-10-28. Original entities.json SHA-256: `d741d877ac77c4194c4ad526b5b4a19aef8dfe411ab840a466891cdbb9f362e6`.

The mapping is specification data, not a parser implementation or runtime dependency. It is embedded so the original single-script browser page works offline.
