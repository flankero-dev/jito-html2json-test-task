# Використання AI під час виконання html2json

Основний діалог: [`chatgpt_chat.txt`](chatgpt_chat.txt).

Додаткові відібрані технічні матеріали:

- [`AI_USAGE_OVERVIEW_UK.pdf`](AI_USAGE_OVERVIEW_UK.pdf) — короткий огляд використання AI та навігація.
- [`WORK_TECHNICAL_SESSION_UK.pdf`](WORK_TECHNICAL_SESSION_UK.pdf) — звіти про реальні технічні перевірки Work (W2, W8, W12, W14, W16).
- [`ADDITIONAL_TECHNICAL_SESSION_UK.pdf`](ADDITIONAL_TECHNICAL_SESSION_UK.pdf) — витяги результатів розробки та тестування, R231–R362.

Це відібрані фактичні результати роботи AI, а не повний експорт діалогів. Іншомовні повідомлення перекладено українською, технічні ідентифікатори збережено. Особисте, HR, чернетки запитів і повторні оцінки прибрано. Частина джерел доступна лише як позначки вкладень. За запитом компанії щодо незміненої повної AI-історії ці витяги самі по собі не є її заміною.
